# Constellation Simulator (development)

Interactive 3D orbital visualization — **active development** branch.

The stable demo lives in [`../constellation-viz`](../constellation-viz).

```bash
cd /Users/chris/Documents/Construction/constellation-sim
npm install
npm run dev
```

Open the URL Vite prints (usually **http://localhost:5175/**). Run `npm run dev` alone — do not paste shell comments on the same line.

See **[ROADMAP.md](./ROADMAP.md)** for the phased plan.
